## ⚠️ 其中四张需要重拍

`shot-01` ~ `shot-04` 是**修复前**截的，画面里每个面板标题都漏出了 `/span>` 字面量
（例如显示成 `▚ /span>CRAWL TOPOLOGY`，而不是 `▚ CRAWL TOPOLOGY`）。

**原因**：早先一次批量文本替换里，`▚` 后面那个 `<` 被误补成了空格，
于是 `<span>▚ /span>` 少了个尖括号，浏览器把 `/span>` 当普通文字渲染了出来。

**已经修好**，并且加了两条断言盯着（HTML 标签配对 / 无裸标签字面量），以后不会再犯。

**所以要做的**：重新打开 `index.html`（代码不用改），按下面清单重拍这四张，
**用同名文件覆盖** `docs/` 里的旧图。

`shot-05-export.png` 是干净的小图裁剪，**不用重拍**。

## 可选：录一段 GIF 当首图

静态图已经够用，但 **GIF 说服力强得多**（能看到虫子爬行、卡片逐条弹出）。

1. 装 [ScreenToGif](https://www.screentogif.com/)（开源免费）
2. 录这 15 秒：拖入 docx → 输入关键词 → `Ctrl+Enter` → 跑 3~4 秒 →
   点 **▤ 覆盖率自检** 停 2 秒 → 鼠标挪到虫子上等气泡出现
3. 导出：**12~15 fps、宽 960~1280、压到 5 MB 以内**
4. 存成 `docs/demo.gif`，然后把 README 首图那行改成：

   ```markdown
   ![界面演示](docs/demo.gif)
   ```

## 图片体积

四张整屏 PNG 各约 1.3~1.9 MB，合计约 6.6 MB。GitHub 能接受，但首屏加载会慢一些。
如果在意，用 [TinyPNG](https://tinypng.com/) 或 `pngquant` 压一下 ——
**压完保持文件名不变**，README 不用改。目标每张压到 500 KB 以内。
