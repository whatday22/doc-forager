## 换图怎么做

1. `Win` + `Shift` + `S` 框选截图（自动存到「图片/屏幕截图」）
2. 拍之前按 `F` **全屏**，窗口调到约 2560×1600
3. **用同名文件覆盖** `docs/` 里的旧图
4. 回到上一层目录重跑：`node 打包发布.mjs`
5. `git add -A && git commit -m "docs: 更新截图"`

### 各张图怎么摆

| # | 文件名 | 怎么摆 |
|---|---|---|
| 1 | `shot-01-local-file.png` | 拖入 `../测试样本/经营分析报告.docx` → 输入 `财务 营收 增长率 毛利率 用户数 市场规模` → `Ctrl+Enter` → **等 `STATE` 显示 `DONE`** 再截 |
| 2 | `shot-02-idle.png` | 点 **重置** 回到空图 → **鼠标挪到虫子身上** → 等气泡把「我可是赛博虫，不是草履虫！」打完整了再截 |
| 3 | `shot-03-simulate.png` | 模式切 **模拟引擎** → 示例·量子 → 启动 → 跑 4~5 秒截 |
| 4 | `shot-04-real-crawl.png` | 模式切 **真实抓取** → 启动 → 抓到几页后截 |
| 5 | `shot-05-export.png` | 跑完后点右下角 **⤓ 导出结果**，把弹出的菜单裁下来（小图即可） |

> 拍 `shot-01` 时别让鼠标停在虫子上，否则彩蛋气泡会挡图 —— 气泡留给 `shot-02`。

## 可选：录一段 GIF 当首图

静态图已经够用，但 **GIF 说服力强得多**（能看到虫子爬行、卡片逐条弹出）。

1. 装 [ScreenToGif](https://www.screentogif.com/)（开源免费）
2. 录这 15 秒：拖入 docx → 输入关键词 → `Ctrl+Enter` → 跑 3~4 秒 →
   点 **▤ 覆盖率自检** 停 2 秒 → 鼠标挪到虫子上等气泡出现
3. 导出：**12~15 fps、宽 960~1280、压到 5 MB 以内**
4. 存成 `docs/demo.gif`，然后把 README 首图那行改成：

   ```markdown
   ![界面演示](docs/demo.gif)
   ```

## 图片体积

四张整屏 PNG 各约 1.3~1.8 MB，合计约 6.3 MB。GitHub 能接受，但首屏加载会慢一些。
如果在意，用 [TinyPNG](https://tinypng.com/) 或 `pngquant` 压一下 ——
**压完保持文件名不变**，README 不用改。目标每张压到 500 KB 以内。

> 自测里有一条断言会检查 README 引用的本地文件是否都存在，
> 所以文件名写错会立刻被抓出来（`node selftest.mjs`）。
